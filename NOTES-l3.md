## 8 fork
## 
## У fork відаленний репозиторій origin вказує на мій репозиторій, а upstream на оригінальний репозиторій. Команди git fetch upstream отримують інформацію про зміну оригіналу, а git push origin відправляє мої зміни до власного репозиторію.
